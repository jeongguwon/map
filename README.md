# 카테고리 기반 국내 지도 앱 - 스캐폴딩

본 저장소는 [prd.md](./prd.md), [trd.md](./trd.md)를 기반으로 한 프로젝트 스캐폴딩입니다.
실제 구현 코드는 포함되어 있지 않으며, 폴더 구조와 각 영역의 책임만 정의되어 있습니다.

## 최상위 구조

- `frontend/` - 지도 렌더링, 카테고리 UI, 장소·경로 패널을 담당하는 SPA (TRD 2장, 3장)
- `backend/` - 외부 API 키 보관, 요청 검증, 응답 정규화, 캐싱을 담당하는 API 프록시 (TRD 2장, 4장)
- `shared/` - 프론트엔드·백엔드가 함께 사용하는 내부 공통 데이터 모델 (TRD 5장)
- `ideation.md`, `prd.md`, `trd.md` - 기획 및 기술 문서 (루트에 위치)

## 착수 전 확인 사항

TRD 1장 및 PRD 11장에 명시된 대로, 지도/장소 검색 API와 도보 경로 API 조합은 PoC 결과에 따라 확정됩니다.
1단계 실제 구현 착수 전 PoC를 먼저 진행하세요.
